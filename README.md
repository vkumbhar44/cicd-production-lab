\# CI/CD Production Lab



A hands-on DevOps and Platform Engineering lab focused on building a production-style CI/CD system.



\## Application



A small Python Flask application used as the workload throughout the lab.



Endpoints:



\- `/` - application information

\- `/health` - health check

\- `/version` - application version



\## CI/CD Evolution



The lab will progressively implement:



Basic CI

→ PR CI

→ Security

→ Docker

→ ECR

→ OIDC

→ Environments

→ Kubernetes

→ Helm

→ GitOps

→ Progressive Delivery

→ Jenkins



\## Technologies



\- GitHub

\- GitHub Actions

\- Jenkins

\- Python Flask

\- Docker

\- AWS ECR

\- Kubernetes

\- Helm

\- Argo CD

\- Terraform

\- Security scanning tools



\## Purpose



This repository is a hands-on learning laboratory for experimenting with production CI/CD patterns, troubleshooting failures, and understanding enterprise DevOps practices.
